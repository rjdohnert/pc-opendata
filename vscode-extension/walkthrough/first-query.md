## Run your first query

Create a file named `scratch.sql` and paste:

```sql
LOAD SAMPLE;
SELECT * FROM SAMPLE_DATA;
```

Click **▶ Run Statement** above either line. Results appear in the results panel.

Tips:
- `LOAD SAMPLE;` creates a five-row practice table — safe to run repeatedly.
- Use **⚡ Benchmark (100x)** to measure a statement, or **🔍 Explain CBO Plan** to see how the engine executes it.
