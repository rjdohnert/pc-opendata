## Open or create a database

PC/OpenData stores each database as a single file (`.pcod`).

- **Open an existing file**: use *File → Open File* and pick a `.pcod`, `.mdf`, or `.dbf` file. It opens in the PC/OpenData Database Inspector.
- **No database yet?** Run the `PC/OpenData: Open Getting Started Database` command to open (or create) `mydata.pcod` in your workspace.

The status bar shows the active database and generation once connected.
